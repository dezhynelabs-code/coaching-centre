# Vijetha Study Circle - Coaching Centre Website

Official website for **Vijetha Study Circle**, a premier competitive examination coaching institute based in Dilsukhnagar, Hyderabad.

## Features

- **Responsive Design**: Optimized for desktop, tablet, and mobile devices.
- **Course Catalog**: Information on TSPSC, SI/Constable, DSC, SSC, and Banking exams.
- **Interactive UI**: Modern layout with smooth interactions and clear call-to-actions.
- **Lightweight Server**: Built-in Node.js static file server with no external runtime dependencies.

## Project Structure

```text
├── assets/

```

## Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v16 or higher recommended)

### Running the Website

1. Start the local server:
   ```bash
   npm start
   ```
   *Alternatively:*
   ```bash
   node server.js
   ```

2. Open your web browser and navigate to:
   ```
   http://localhost:3000
   ```
